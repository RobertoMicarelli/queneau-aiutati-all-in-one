# Queneau · AI-UTATI All-in-One

Esperienza didattico-creativa in un solo file HTML: cinema in sette atti, 25 voci ElevenLabs, immagini, laboratori interattivi e making-of della regia.

## Uso locale

Apri `index.html` con Chrome, Edge o Safari. Il file non richiede server e non carica risorse multimediali esterne.

## Pubblicazione

La cartella è pronta per GitHub Pages e Vercel. Tutte le risorse dell'esperienza sono incorporate in `index.html`.
